# Mac125 for Windows

Mac125 for Windows is a free companion application for the Uniden UBC125XLT scanner.

It provides a native Windows workspace for connecting to your scanner, viewing live status, managing channels, working with banks and ranges, creating backups, and using supported scanner controls.

## Download

Download the latest Windows installer from the [Releases](../../releases) page.

The installer is self-contained for 64-bit Windows. No separate .NET runtime installation is required.

## Install

1. Download `Mac125-Setup-vX.Y.Z-win-x64.exe` from the latest release.
2. Optionally verify its SHA-256 checksum using the matching `.sha256` file.
3. Run the installer.
4. Launch Mac125 from the Start Menu or desktop shortcut.
5. Use **Discover** to find your scanner, then select its USB serial port and choose **Connect**.

## Before Writing to Your Scanner

Create a full scanner backup before making important changes.

Mac125 includes confirmation and readback safeguards for supported write operations, but your scanner data remains your responsibility. Reinstalling or reverting Mac125 does not undo changes already made to the scanner.
